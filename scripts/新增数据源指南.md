# 新增数据源指南

本文档说明如何为列表页发现爬虫（`crawler_discover.py`）接入一个新的招聘公告数据源。
全程只需改两个文件：`scripts/probe_sources.py`（探测）和 `config.py`（配置），**不需要写任何爬虫代码**。

---

## 流程总览

```
找列表页 URL → 探测站点结构 → 分析链接规律 → 写配置 → 单源试跑 → 提交
```

---

## 第 1 步：找到列表页 URL

浏览器打开目标站点（省人社厅 / 省委组织部 / 人事考试网 / 国企招聘平台），找到**公告列表栏目**
（"通知公告"、"招聘信息"、"选调生专栏"、"公务员考试"等），复制栏目页地址。

> ⚠️ 要的是**栏目列表页**（页面里有一排公告链接），不是某一条公告的详情页。

---

## 第 2 步：探测站点结构

编辑 `scripts/probe_sources.py`，把候选 URL 加进 `CANDIDATES` 列表：

```python
CANDIDATES = [
    ...
    {"name": "某某省人社厅", "url": "https://xxx.gov.cn/tzgg/"},   # ← 新增这行
]
```

运行（本机 Python 3.14 路径，如已配 PATH 可直接 `python`）：

```powershell
C:\Users\35586\AppData\Local\Programs\Python\Python314\python.exe scripts/probe_sources.py
```

探测结果自动写入 `scripts/probe_result.txt`（UTF-8，用 VS Code 打开查看，避免控制台乱码）。

### 判读标准

| 探测结果 | 含义 | 结论 |
|---|---|---|
| `[OK]` 且列出链接样本 | 列表是静态 HTML，可爬 | ✅ 可接入 |
| `[WARN]` 页面过小（<5000 字节） | JS 动态渲染，爬虫拿不到列表 | ❌ 放弃 |
| `[WARN]` 无链接样本 | 同上，或内容区异步加载 | ❌ 放弃 |
| `[FAIL]` 网络/SSL 错误 | 站点 TLS 配置特殊或被反爬拦截 | ❌ 放弃 |

> 实测经验：政府站点 JS 渲染比例很高，10 个候选里能中 2-3 个算不错，多试几个省份。
> 已确认不可用的源（2026-08 实测）：四川（JS 渲染）、贵州/重庆/河南（SSL 失败）、
> 江西（内容异步加载）、河北（JS 渲染）、安徽（SSL 自签名证书）、青海（JS 渲染）、
> 高校人才网（403 反爬）、国家大学生就业服务平台（JS 渲染）。

### 判断 JS 渲染的土办法

浏览器打开列表页 → `Ctrl+U` 查看网页源代码 → 搜索公告标题文字：
搜得到 = 静态可爬；搜不到 = JS 渲染，放弃（除非上 Playwright，成本高，不建议）。

## 第 3 步：写配置

在 `config.py` 的 `LIST_SOURCES` 列表末尾加一条。**复制模板，改 6 个字段即可**：

```python
{
    "name": "源名-栏目名",                    # 日志/报告里显示的名字
    "source": "来源字段值",                    # 入库数据的 source 字段（前端按此筛选）
    "category": "事业单位",                    # 默认分类（详情页没解析出分类时兜底）
    "list_url": "https://xxx.gov.cn/tzgg/",    # 第 1 步找到的列表页 URL
    "url_regex": r'/20\d{4}/t\d+\.html',       # ★ 公告链接规律（见下方说明）
    "title_min_len": 8,                        # 标题最短长度（过滤导航链接）
    "keywords": None,                          # 标题关键词白名单；None=全收
    "max_links": 25,                           # 每轮最多爬多少条
    "pagination": None,                        # None=不翻页
    # 翻页则写: {"pattern": "index_{n}.html", "max_pages": 2}
},
```

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 唯一，日志与健康报告用 |
| `source` | ✅ | 入库数据的来源标记 |
| `category` | ✅ | 详情解析失败时的分类兜底 |
| `list_url` | ✅ | 列表页地址，需以 http(s) 开头 |
| `url_regex` | 二选一 | 公告链接必须匹配的正则 |
| `url_contains` | 二选一 | 公告链接必须包含的子串列表（正则难写时用这个） |
| `url_excludes` | 可选 | 链接不能包含的子串（排除导航/历史栏目） |
| `title_min_len` | ✅ | 过滤短标题的导航链接 |
| `keywords` | 可选 | 标题关键词白名单；`None`=不过滤 |
| `max_links` | ✅ | 单源每轮最多爬取的详情条数 |
| `pagination` | 可选 | 翻页模板；`None`=不翻页 |

### url_regex 怎么写

看探测输出的链接样本，找共同规律。已接入源的示例：

| 源 | 样本链接 | url_regex |
|---|---|---|
| 中央机关 | `.../202608/t20260810_581811.html` | `r'/20\d{4}/t20\d{6,8}_?\d*\.html'` |
| 山西选调 | `.../202606/t20260626_10161293.shtml` | `r'/20\d{4}/t20\d{6,8}_?\d*\.shtml'` |
| 广东 | `.../tzgg/content/post_24725.html` | `r'/tzgg/content/post_\d+\.html'` |
| 国资委 | `.../n2588035/n2588350/c35747841/content.html` | `r'/n2588035/n2588325/n2588350/c\d+/content\.html'` |
| 广西 | `.../2026ngwygg/t32380.html` | `r'/(20\d{2}ngwygg|20\d{2}nxdsgg)/t\d+\.html'` |
| 辽宁 | `/html/gwy_zhaokaogonggao/7341.html` | 用 `"url_contains": ['/html/gwy_zhaokaogonggao/']` 更简单 |

> ⚠️ URL 里的日期数字不要写死年份（如 `/2026`），用 `\d{4}` 代替，否则跨年后失效。

### 翻页配置

列表页第 2 页地址形如 `index_2.html` 时：

```python
"pagination": {"pattern": "index_{n}.html", "max_pages": 2},
```

`{n}` 会被替换为页码（第 1 页自动用 `list_url`）。框架自带同页检测：翻页后发现链接与
上一页完全重复会自动提前停止，不会死循环。不确定站点是否支持翻页时，直接写
`"pagination": None`，只抓第 1 页最稳妥。

---

## 第 4 步：单源试跑

只跑新源，不影响其他源：

```powershell
C:\Users\35586\AppData\Local\Programs\Python\Python314\python.exe crawler_discover.py --source 源名
```

验证三件事：

1. 首次运行：`发现 N 个, 新增 N 条, 失败 0 条`（失败多说明 url_regex 或详情页解析有问题）
2. 再跑一次：`新增 0, 跳过 N`（增量机制生效）
3. 抽查 `data/all_jobs.json` 末尾新源数据：标题、内容、日期、来源字段是否正常

---

## 第 5 步：提交

```powershell
git add config.py data/
git commit -m "feat: 新增某某省数据源"
git push
```

之后每天 8 点 GitHub Actions 自动运行，新源自动发现新公告入库。

---

## 站点改版后怎么修

1. CI 健康度检查会自动创建 Issue，列出异常源
2. 用探测脚本重新探测该站点，看链接规律是否变化
3. 按新结构更新 `config.py` 中对应源的 `url_regex`/`list_url`
4. push 后到 GitHub Actions 页面手动触发 `workflow_dispatch` 重跑验证
